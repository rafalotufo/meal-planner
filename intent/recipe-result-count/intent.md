# Recipe result count

Rafael reports only three results for common searches such as chilli and pizza
and expects more. Treat the existing six-card capacity as the target for broad
queries rather than an optional upper bound in research instructions.

The local UI retains all returned cards. The provider currently requests “up to
six”, permits early completion, and independently drops invalid or duplicate
records. No captured live response establishes which of those occurred for the
reported searches.

Acceptance: explicitly seek six distinct, relevant, source-supported recipes;
continue discovery within existing limits when sources are unsuitable. Allow
fewer when constraints, source availability or the existing budget prevent six.
Never pad with invented or unsupported recipes. No deployment is authorized.
