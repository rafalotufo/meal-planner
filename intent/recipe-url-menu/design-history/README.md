# Superseded Design history

`synchronous-spec.md` preserves the original draft specification byte-for-byte.
It was not owner-approved. The owner subsequently requested immediate durable
link saving followed by asynchronous curation and same-entry update, then chose:
“Keep it simple: save safely, start curation, and offer Retry if interrupted.”

The active sibling `../spec.md` supersedes this synchronous draft. This archive
is historical evidence, not current scope or implementation/release authority.
